# Final-Project--Bayan-bilingual-citizen-feedback
# Project Overview: This is an AI-powered system designed to process citizen complaints and suggestions. It serves municipal operations by automatically sorting incoming text requests into administrative categories and allowing agents to immediately find historically resolved cases that match new incoming issues—even if they are written in a different language or dialect.
# Problem Description: Municipal operational centers deal with large volumes of unstructured, multi-dialectal, and bilingual feedback daily. Operational bottlenecks include:
1. **Topic Classification**: Inconsistent classification of incoming complaints due to dialectal nuances (e.g., Gulf vs. Egyptian Arabic vs. MSA) and varying feedback lengths.
2. **Historical Case Retrieval**: The inability of customer service agents to quickly locate previous resolutions for similar historical issues, resulting in slow and disjointed manual routing.
3. **Ambiguity and Noise**: Short, vague, or multi-topic messages that cannot be accurately categorized by simple rule-based parser
